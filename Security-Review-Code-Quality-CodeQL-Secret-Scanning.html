01 · Security Review

Make review useful.
Keep judgment human.

Copilot code review helps surface mechanical issues while context is still fresh.

01
Where to use it

Before and during a pull request

  • On GitHub: request a review or enable automatic PR reviews.
  • In the editor: review a selection or all uncommitted changes before opening a PR.
  • Use it to spot error paths, missing tests, and inconsistencies.
Set standards

Give the reviewer local rules

Use repository-wide Copilot instructions and path-scoped instruction files to describe project conventions and high-risk patterns.

Example: flag unchecked errors or unsafe allocation in a real-time path; skip formatting already enforced by CI.

Human responsibility

Review the finding, not just the wording

Confirm the issue is real, inspect the proposed change, and run the relevant tests. The reviewer can assess code mechanics; people still own product intent and risk decisions.

!

Team practice: Treat AI comments as review suggestions. A clean automated review is not proof that a change is secure or correct.

04 · Secret Scanning

Stop a secret
before it spreads.

Detection helps find exposed credentials; prevention and fast rotation limit the damage.

Secret scanning

Find exposure across repository content

Scanning checks Git history, not just the latest commit. Removing a leaked value from the current file does not make the old credential safe.

Custom patterns can cover organization-specific token formats; validity checks can help prioritize credentials that may still work.

Push protection

Block supported secrets before they land

When a push is blocked, the contributor can remove the secret and retry. Any bypass should follow the organization's policy and be auditable.

Response

Rotate first, then clean up

Revoke or rotate a real credential immediately. Then remove it from code and history as needed, investigate use, and close the alert accurately.

!

Operational priority: Enable push protection to stop new exposure while teams work through historical findings. A secret that has been committed should be treated as compromised.
